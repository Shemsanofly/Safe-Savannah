# models/

Generated by `python scripts/export_model.py --weights yolo11n.pt --out models`:

- `yolo11n.onnx`: exported detector (git-ignored)
- `yolo11n.manifest.json`: SHA-256 pin, input size, and the class labels the TypeScript detector uses to find
  `elephant` **by label** (git-ignored, because every export has a different hash)

The detector refuses to start if the checksum doesn't match. Run `npm run model:check` to verify.
Ultralytics weights are AGPL-3.0: review the licence before sharing or deploying.
